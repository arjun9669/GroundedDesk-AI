# NextConfirm64 solo-maintainer evaluation protocol

This is an author-aware engineering evaluation of the isolated `coverage-v50-versioned-retention` browser module at Git commit `377dbcab9457f3f215e6036b4471936df35df572`. The application and live 5.6/r44 deployment stay as published. Codex authored the pack, had access to the candidate and prior results, and completed a separate source-to-key review. The original independent-review ledger, Phase 2 acceptance decision, Fresh64 FC61 failure, and release hold retain their existing status.

Use the eight original TXT sources and exact case order, question strings, pairs, and key from `eval/nextconfirm64`. No benchmark inputs were submitted during neutral MiniLM setup. The original native `gradeAnswer` and the historical v50 quotation and vector audit apply. Each logical variant needs 64 native PASS, zero false acceptances and refusals, and no unresolved integrity failures to meet this engineering target. Passing this target does not satisfy independent release acceptance.

Use installed Google Chrome headless on Windows with the browser-side Transformers.js feature-extraction pipeline `Xenova/all-MiniLM-L6-v2` q8 and WASM. No generation pipeline is loaded. Execute 56 Hybrid questions against fixed and section indexes using real vectors, and eight lexical Comparison questions using their specified pairs. Each lexical result contributes to both logical totals from the same capture. There are 64 unique questions and 120 variant outputs. The page displays isolated candidate results for screenshots. It does not exercise the live application's Q&A UI or score live r44. No paired candidate or mock vectors are used.

Freeze the runner, candidate dependency closure, exact sources, case list, answer key, and neutral runtime/asset proof before the first question. Verify the same assets at capture startup. Use a new raw directory and preserve every result and screenshot once. Stop on execution failure and retain partial files. Seal raw hashes before loading the key for grading. Grade completeness, relevance, provenance, citation integrity, and false acceptance/refusal. Record binding-audit failures separately from native grades. Report all results and avoid tuning on the pack.
